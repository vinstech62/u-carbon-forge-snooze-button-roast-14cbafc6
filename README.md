A deterministic Node program that writes one line roasting an alarm clock that rings at 6 AM on a Saturday morning, for make.fun's Snooze Button Roast bounty. No dependencies, no network, no randomness — the same line every run.

## Run it

```sh
node main.ts
```

It writes the roast to `/output/entry.txt`.
